# Reference: Legacy 21 CFR 820 Citations in QM Documents

**Date:** 2026-03-24  
**Purpose:** Catalog of every explicit legacy 820 section citation found in the 46 QM documents. These citations reference the old 21 CFR Part 820 subpart structure that has been replaced by the QMSR (effective February 2, 2026). This data tells the gap analysis agent exactly which documents contain regulatory references that may need updating.

---

## Summary

**19 of 46 QM documents contain explicit 820.xx section references.**

These citations appear in each document's "References" or "Applicable Standards" section and/or in purpose statements. They cite specific legacy 820 subparts.

## Key Observations

1. **Most citations are in the "References" section** — a standardized block near the top of each SOP that lists applicable regulations and standards. Updating these is a targeted, bounded task.

2. **Two documents embed 820 references in body text:**
   - QM.SLQ017 (Internal Audits) references 820 in auditor qualification criteria and checklist requirements
   - QM.SLQ018 (Management Review) references §820.20(c) in a paragraph about FDA inspector interactions

3. **Three documents cite 820 in purpose statements** (QM.SLQ004, QM.SLQ006, QM.SLQ007) — these reference 820.30 alongside ISO 13485:2016 as dual compliance targets.

4. **27 documents contain NO explicit 820 citations.** These may still need review for implicit regulatory assumptions, but they do not contain literal 820 section numbers.
