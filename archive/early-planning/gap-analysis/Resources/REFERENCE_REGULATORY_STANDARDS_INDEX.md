## Core Standards for Gap Analysis

These are the primary regulatory documents needed for the QMSR / ISO 13485 gap analysis.

### FDA QMSR Final Rule (87 FR 68905 / 89 FR 7496)

The Federal Register document establishing the new 21 CFR Part 820 that incorporates ISO 13485 by reference, with FDA-specific supplementary provisions.

| Item | Path |
|---|---|
| **Full rule text** (extracted) | `docs/QMS-Readable-Texts/11-RegulatoryStandards/ISO -- 2024-01709. FDAQMSRFinalRule.md` |
| Original PDF | `RegulatoryStandards&Approvals/ISO/2024-01709. FDAQMSRFinalRule.pdf` |

**Key sections to focus on:**
- Summary of Major Provisions (what changed)
- Supplementary Provisions (§820.35, §820.45, etc. — FDA requirements beyond ISO 13485)
- Conforming Amendments (how legacy 820 sections map to the new structure)
- Effective Date and Implementation Strategy

## Quality Manual Exclusions

Per the Quality Manual (QM.SLQ027 Rev E), the following ISO 13485:2016 clauses are explicitly excluded with justification:

| Clause | Topic | Exclusion Rationale |
|---|---|---|
| 7.5.3 | Installation activities | No products require installation; shipped ready to use |
| 7.5.4 | Servicing activities | No products require servicing |
| 7.5.9.2 | Particular requirements for implantable devices | No implantable medical devices |
| 7.5.10 | Customer property | No physical customer property used (patient data handled per QM.SLQ028) |
